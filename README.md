# JinglinWang.github.io

Personal website for Jinglin Wang, ready to host with GitHub Pages.

## Files

- `index.html` is the homepage.
- `styles.css` contains the site styles.

## Publish

Create a GitHub repository named `JinglinWang.github.io`, then run:

```bash
git init
git add .
git commit -m "Create personal website"
git branch -M main
git remote add origin https://github.com/JinglinWang/JinglinWang.github.io.git
git push -u origin main
```

After pushing, open the repository on GitHub and confirm Pages is publishing
from the `main` branch root. The site will be available at:

```text
https://JinglinWang.github.io
```
